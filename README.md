A modern and responsive e-commerce website designed for selling technology products such as laptops, smartphones, headphones, speakers, and other accessories.

Features
🛒 Shopping Cart
❤️ Saved Wishlist
🔐 Sign Up & Sign In
📱 Responsive & Modern UI
✨ Interactive 3D Visual Effects
🛍️ Smooth Product Browsing & Shopping Experience
About the Project

This project was built using vibe coding and AI-assisted development, focusing on creating a professional, user-friendly, and visually engaging e-commerce experience.

The project demonstrates how modern AI tools can be used to design and develop a complete e-commerce interface with essential shopping features.
